# Webdro Website

This is an editable React/Vite rebuild inspired by the supplied Antimatter AI production site.

## Run
1. Open a terminal in this folder.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL shown by Vite.

## Current Webdro changes
- Antimatter service list replaced with 8 Webdro services.
- Tools/technology lists removed from service cards.
- Service cards redesigned with hover interaction.
- Case-study/work area replaced with Undr Ctrl Burgers and Anvith Dazzle placeholders.
- About, contact and footer are Webdro-specific.
- Colors intentionally remain close to the supplied site's dark/violet visual direction for now.
- Project visuals are CSS placeholders so you can later replace them with the real project screenshots.

Main editable files:
- `src/App.jsx`
- `src/styles.css`
